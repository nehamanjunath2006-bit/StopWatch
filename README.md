# Premium Stopwatch

A modern stopwatch web app built with React, Next.js, TypeScript, Tailwind CSS, Framer Motion, and Zustand.

## Features

- Large digital HH:MM:SS:MS display
- Start / Pause / Resume / Reset controls
- Lap recording with scrollable history
- Multiple independent stopwatch tabs
- Fast, drift-free timing using `performance.now()`
- Dark / Light theme toggle
- Sound and vibration feedback options
- Fullscreen mode
- Persistent local storage state
- Export laps to CSV and share results
- Responsive premium UI with glassmorphism and smooth animations
- PWA-ready manifest

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Deploy on Vercel by connecting the repository and using the default Next.js build settings.
